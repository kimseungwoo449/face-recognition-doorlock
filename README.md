# 🙋‍♂졸업작품
--------------
## 🐟라즈베리파이를 활용한 안면인식 도어락

기존의 도어락은 비밀번호 노출, 카드키 분실등의 보안 및 편의적인 문제점이 있다.

이에 인공지능 안면인식 기술을 도입해 보안성과 편의성을 증대시키는 도어락을 제작해 보고자 하였다.

----------------------
## 📌1. 개발환경
* **Raspberry Pi 4 Model B(4G) - (OS)BUSTER 32bit**
* **App Inventor**
* **Python - 3.7.3 version**
* **사용한 라이브러리**
  1. OpenCV - 4.2.0 version
  2. NumPy
  3. Python-bluetooth
  4. Flask


-----------------------
## 📌2. 동작 설명

1. 앱을 통한 사용자 등록 및 얼굴 학습
  * 어플리케이션의 **새로운 이용자** 버튼을 클릭한다.
  * 사람의 얼굴을 Haar검출기를 이용해 검출하고 흑백으로 변환해 총 50장 저장한다.
  * OpenCV에서 제공하는 LBPH알고리즘 기반의 학습을 시작한다.
  * 학습결과를 저장 후 부저를 울린다.

2. 등록된 유저의 얼굴을 이용해 잠금해제
  * 얼굴검출을 용이하게 하기위해 초음파 센서를 이용해 일정거리가 되면 검사를 시작한다.
  * 학습된 모델을 불러온다.
  * 얼굴을 검출해 기학습된 모델과 비교한다.
  * 알고리즘을 통해 인식도가 80%이상일 시 릴레이모듈을 제어해 잠금을 해제한다.
  * 80%미만일 시 방문자로 간주해 사진을 저장한다.

3. 방문자 사진 확인
  * 방문자가 존재, 즉 저장된 사진이 존재하면 앱에 알림을 띄운다.
  * 사용자가 **방문자 사진** 버튼 클릭시 로컬웹페이지를 생성해 해당 사진을 웹을 통해 확인한다.

4. 앱을 통한 도어락 제어
  * 앱의 **잠금해제** 버튼 클릭 시 블루투스를 통해 제어문자열을 서버에 전송한다.
  * 해당 제어문자열을 받은 서버는 릴레이모듈을 조작해 도어락의 잠금을 해제한다.
